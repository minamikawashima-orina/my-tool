# my-tool

シンプルで軽量なランディングページのプロジェクトです。

## 概要

`my-tool` は、余計な依存関係を持たない、静的HTML/CSSだけで構成されたシンプルなランディングページです。ビルドツールや外部ライブラリを使わずに、そのままブラウザで開いて確認できます。

## 特徴

- ⚡ **高速** — ビルドプロセス不要。素のHTML/CSSのみで動作します。
- 🎯 **シンプル** — ファイル構成がシンプルで、誰でもすぐに内容を把握・編集できます。
- 🔧 **拡張可能** — 必要に応じて自由にセクションやスタイルを追加できます。

## 使用技術

- HTML5
- CSS3

## 使い方

1. リポジトリをクローンします。

   ```bash
   git clone https://github.com/minamikawashima-orina/my-tool.git
   cd my-tool
   ```

2. `index.html` をブラウザで直接開きます。

   ```bash
   open index.html
   ```

3. 内容を編集する場合は `index.html`（構成・文言）と `style.css`（デザイン）を編集してください。
